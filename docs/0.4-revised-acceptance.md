# ClipRiva 0.4 修订版：实现方案与验收用例

## 范围与非目标

0.4 继续保持本地优先、无需账户和不上传剪贴板内容。版本的目标不是增加一个
新的工作台，而是补齐「找得准、贴得明白、删不丢」的可靠性闭环。

- **P0 恢复反馈：** 区分已恢复到系统剪贴板、已向目标应用发送粘贴、未能发送但
  内容仍在剪贴板三种可验证结果；失败原因仅为权限、焦点或兼容性类别。
- **P0 安全清理：** 单条、批量和保留策略共享影响预览；删除先进入本地回收站，
  再按可预测的期限永久清除。
- **P0-lite 精确分组：** 只按本地精确内容哈希分组，保留每个版本的来源、时间和
  置顶状态，默认折叠且默认操作单个版本。
- **P1 隐私处理与诊断：** 被拒绝捕获的原因可进入正确设置项；诊断是用户可关闭、
  仅记录结果与粗粒度时间的本地能力。
- **数据约束：** 迁移保留已有记录；记录具备稳定 ID、来源设备、精确内容哈希、
  组、版本、删除和恢复时间，为未来独立设计的同步层预留字段。

明确不包含账户、同步入口、云端/默认 AI、语义或模糊去重、图片内容指纹、自动删除
重复项和面向普通用户的运营分析页。

## 设计原则

1. **只陈述系统能够验证的事实。** Direct Paste 只能确认已向目标应用发送粘贴，
   不把输入框最终写入称作成功。
2. **默认可逆，危险操作分层。** 普通清理进入本地回收站；清空回收站或永久删除单独
   确认且不可恢复。
3. **精确而非猜测。** 只将完全相同的本地内容归组；空白、换行、大小写和任意细微差异
   都保持为不同内容。
4. **诊断不保存内容。** 不记录原文、文件名、路径、应用内文档名、网络标识或可复原
   内容指纹；报告仅在用户主动导出时生成。

## 自动化验收矩阵

| ID | 场景 | 关键操作 | 通过条件 |
| --- | --- | --- | --- |
| TC-01 | 恢复状态 | Restore、Direct Paste 成功和失败 | 分别显示「已恢复到剪贴板」「已向目标应用发送粘贴」「未能发送，内容仍在剪贴板」；敏感项不回显原文。 |
| TC-02 | 权限与焦点降级 | 撤销辅助功能权限、切换/关闭目标应用、只读输入框 | 不注入到错误目标；内容仍在剪贴板；失败原因可解释且可重试。 |
| TC-03 | 重试与历史 | 连续重试、其他应用改写剪贴板 | 重试不新增 History；剪贴板被改写时给出可解释结果。 |
| TC-04 | 清理预览 | 单条、批量和策略清理 | 预览显示影响数、置顶跳过、规则、非敏感代表项和回收站期限；三个入口用语一致。 |
| TC-05 | 回收站期限 | 删除、重启应用/系统、到期、清空和永久删除 | 删除可恢复；期限为 `min(7 天, 原保留期剩余时间)`；到期、清空和永久删除不可恢复。 |
| TC-06 | 恢复语义 | 恢复带来源、置顶和分组记录的条目 | 保留 `captured_at`、来源、置顶和分组；写入 `restored_at`；列表不强行移动到顶部。 |
| TC-07 | 精确重复分组 | 同内容多次复制；仅空白/换行/大小写变化；搜索旧版本 | 相同内容默认折叠、可展开；细微差异不合并；搜索命中旧版本时自动展开并定位。 |
| TC-08 | 组内操作 | 对单版本及明确「全部版本」执行置顶、删除和恢复 | 默认只影响所选版本；全部版本入口显示受影响版本数；不自动删除重复项。 |
| TC-09 | 隐私处理 | Default/Strict 拒绝、恢复 Capture、系统策略限制 | 原因卡可进入规则或排除应用；Strict 恢复二次确认且不关闭保护规则；限制不循环弹窗。 |
| TC-10 | 本地诊断与迁移 | 开关诊断、记录事件、清空/导出、从 0.3 升级 | 诊断无内容性字段且可立即关闭/清空；匿名导出不含禁记字段；迁移可回滚且历史不丢失。 |

## 发布门槛

1. `pnpm check`、全部 Vitest、`cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings` 和 `cargo test` 通过。
2. 自动化覆盖 TC-01 至 TC-10 的可模拟部分；迁移至少验证空库、已有 0.3 历史与升级失败回滚。
3. 在真实 macOS 上人工验证：Xcode、Safari、Notes、Mail 与至少两个第三方应用中的恢复/回收站；辅助功能授权、焦点切换和重启后剩余期限。
4. 如果 P0-lite 分组有性能或迁移风险，可保持其开关关闭，不阻断恢复与回收站发布；其余 P0 必须全量通过。
