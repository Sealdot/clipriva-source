# Archived M1 + M2 execution plan

> Historical note: this document records the implementation sequence that produced the initial
> clipboard and local-experiment foundation. The active product scope and release gates now live in
> [roadmap.md](roadmap.md). M2 features ship as ClipRiva Labs and are disabled by default.

## Outcome sequence

M1 makes ClipRiva dependable for daily clipboard use. M2 builds on that trusted local data model to make retrieval faster and safer. The order below keeps privacy and local control ahead of intelligence features.

## Workstreams and dependencies

| Workstream | Scope | Depends on | Delivery wave |
| --- | --- | --- | --- |
| M1.1 Desktop lifecycle | Tray menu, close-to-tray, explicit quit, launch at login | Existing windows | 1 |
| M1.2 Capture attribution | Foreground source app provider with safe fallbacks | Existing monitor | 1 |
| M1.3 Capture policy | Retention, deny-list, sensitive-content pause and settings model | M1.2 for app-aware rules | 2 |
| M1.4 Rich content records | Image, RTF and file-reference envelopes with local blob references | M1.3 policy gate | 3 |
| M1.5 Retrieval and accessibility | FTS ranking, keyboard list navigation, focus states, labels and announcements | M1.4 record model | 3 |
| M2.1 Enrichment contract | Versioned deterministic classification, summaries, entities and tags | Existing text record | 1 |
| M2.2 Enrichment persistence | Versioned local enrichment records and query APIs | M2.1 | 2 |
| M2.3 Semantic adapter | Replaceable embedding contract and hybrid retrieval | M2.2 | 3 |
| M2.4 Actions and audit trail | User-defined transformations with reversible history | M2.2 | 4 |
| M2.5 Redaction preview | Explicit preview and approval before a cloud action | M1.3, M2.4 | 4 |

## Current implementation status

- [x] M1.1 Tray/menu-bar lifecycle, close-to-tray and launch-at-login.
- [x] M1.2 Best-effort macOS source-application attribution with safe fallback elsewhere.
- [x] M1.3 Retention, app deny-list, sensitive-content pause and local settings.
- [x] M1.4 Image capture with content-addressed local PNG blobs and copy-back. RTF and file
  representation storage is ready; their macOS pasteboard capture remains pending.
- [x] M1.5 FTS5/BM25 text ranking, keyboard navigation and accessible list states.
- [x] M2.1 Versioned deterministic classification, redacted summaries, entities and tags.
- [x] M2.2 Local enrichment persistence and read API.
- [x] M2.3 Serializable semantic-adapter contract with an offline lexical fallback, connected to a
  switchable local search mode. Vector-provider integration remains pending.
- [x] M2.4 User-defined allow-listed transformations with immutable, redacted audit history.
- [x] M2.5 Preview-only cloud boundary with exact redacted payload and audit record. No cloud action
  executor exists in this release.

## Acceptance gates

1. No denied, paused or expired content reaches storage or enrichment.
2. All M2 enrichments are deterministic, schema-versioned and locally generated by default.
3. A user can reach, navigate and restore a recent clip without opening the main window.
4. Any future cloud action shows the exact redacted payload and requires an explicit approval.
