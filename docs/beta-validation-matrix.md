## v0.9 Local Link Preview / 双真机 Alpha

> 本节是 v0.9 历史门槛记录，不代表当前生产适配器状态。v1.5 已实现默认关闭、用户显式
> 启用的原生 listener/mDNS、Noise 双端 SAS 配对和文本交付；当前候选应执行
> `docs/clipriva-1.5-implementation-and-acceptance.md` 的双真机 Gate。以下历史行不得用于证明
> v1.5 已通过，也不得把同机 TCP/loopback 结果写成双真机证据。

> 本节必须使用两台不同的真实 Mac、独立应用数据与真实网络路径。不得用浏览器 fixture、
> 同机双进程、注入 transport、loopback 或单元测试填写“通过”。证据需记录构建 Git SHA、
> 两台 Mac 的 macOS/芯片、网络类型、Noise 参数/协议版本、日期和测试人；只使用合成文本、
> 合成设备名和脱敏抓包摘要。50 次首配、200 条文本与所有绝对 No-Go 行未通过前，Local Link
> 保持默认关闭和 Preview/Alpha，最终结论为 No-Go。
>
> 当前 v0.9 工程候选的生产适配器仍为 fail-closed：不启动 listener/mDNS、不建立配对/会话、
> 不投递正文。严格 Receipt/状态 schema、Keychain reset、deadline worker、native reveal 意图和
> same-host TCP pre-gate 都不是双真机证据。因此真实传输行均不得填写通过；只有 fail-closed
> 观察项及单机工程预检可执行，其余保留为未来门槛。
