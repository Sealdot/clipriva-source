# ClipRiva 0.6 实施设计与验收计划

- **版本主题：** Local Link / 本地设备互传
- **方案日期：** 2026-07-27
- **状态：** 实施、测试与发布门槛基线；不是发布声明
- **产品输入：** 维护者本地提供的 0.6 产品方案文档（未纳入仓库）

## 1. 结论与实施状态

产品方案的方向是对的：0.6 只解决“主动将一条选中的内容交给另一台 Mac”，不做历史同步、账号或云服务。但当前代码只能交付一个安全默认关闭的 **Local Link 控制面预览**：本地偏好、设备信任状态、配对码哈希、内容无关传输状态、发送前隐私检查，以及显式的测试/loopback seam。

生产默认 transport 明确不可用：它不打开 socket、不广播服务、不进行 mDNS/Bonjour 发现、不建立 LAN 连接、不传送任何内容，也不提供加密通道。因此，本版本不能描述为已实现“局域网互传”“同网发现”“端到端加密”或“文件传输”。浏览器开发适配器和 in-process loopback 仅用于 UI/状态测试，不能替代真实双机验证。

| 已实现并可验收 | 尚未实现，必须保持未通过 | 明确不在 0.6 P0 |
| --- | --- | --- |
| 默认关闭的 Local Link 偏好；本地 Device/Transfer 元数据；六码配对意图；撤销；窄 IPC 状态；本地发送资格检查；`transportUnavailable` 失败降级 | 真实发现、双端身份认证、密钥协商、经验证的加密通道、对端可达性、真实文本/图片/文件投递、跨机接收、网络失败恢复、双 Mac 性能与安全证据 | 账号、Apple ID 绑定、云端中继、互联网/离线投递、自动全历史同步、冲突合并、团队共享、跨平台客户端、自动图片/文件接收 |

### 已知发布门槛（阻断）

1. 0.5 的真人 macOS P0 验收仍是待执行证据。权限、快捷键/焦点、全屏/多显示器/Space、休眠唤醒、异常退出、1 万/5 万历史、升级迁移和网络观察必须在 `docs/beta-validation-matrix.md` 中有可复查通过记录。
2. Local Link 的真实网络能力尚未实现。因此所有涉及配对双方、实际发送/接收、加密、网络切换、文件落盘和双 Mac 成功率的产品方案 P0 行都为 **No-Go**，不是“待补充的小优化”。
3. Local Link 一旦从控制面预览变为真实 transport，必须先更新本计划、`PRIVACY.md`、`docs/privacy/data-flow.md`、`docs/open-source/module-boundary.md`，并增加对应自动化和双真机证据。

## 2. 范围、用户路径与语言

### 2.1 P0 目标路径（真实 transport 后才可开放）

1. 用户在 Quick Paste 或 History 选中一个内容。
2. 用户选择“发送到…”，选择已信任且实际在线的设备。
3. 发送前重新执行暂停、忽略 App、敏感内容、内容类型、大小和文件可读性检查。
4. 在已审查的认证加密会话中，传送该 Item 的一个 Variant 或文件实际字节。
5. 接收端显示来源设备、类型、大小和安全摘要；用户复制、保存或拒绝。
6. 只有用户接受后，才按本地规则创建/合并 Item、Occurrence、Variant 或保存文件。

界面使用“内容、设备、发送、接收、复制、保存、撤销信任、传输记录”。`Item`、`Occurrence`、`Variant`、peer、endpoint、session、handshake 仅用于开发、诊断和支持材料。

| 入口 | 设计约束 | 当前可交付状态 |
| --- | --- | --- |
| Quick Paste | 仅选中 Item 后才显示“发送到…”。建议 `Shift-Command-S`，允许修改；`Enter` 仍是本机粘贴。 | 可做交互/失败状态；不得伪装内容已发送。 |
| History 详情/菜单 | 提供发送动作，不在每条列表行堆设备按钮。 | 可做本地状态预览。 |
| Settings → Devices | Local Link 开关、本机名称、设备状态、配对、撤销。发现和自动接收必须分离。 | 默认关闭；生产没有真实发现。 |
| 接收卡片 | 默认每次询问，复制/保存/拒绝清楚区分。 | 只能通过 test seam 覆盖，不能宣称跨 Mac 已接收。 |
| Menu Bar → Transfers | 只显示内容无关状态和重试入口。 | `transportUnavailable` 必须解释为“尚未可用”，不是“同步中”。 |

### 2.2 内容边界

| 类型 | 真实 P0 设计 | 当前控制面预览 |
| --- | --- | --- |
| 文本 / URL | 发送选定文本 Variant；接收确认复制后再写 History。 | 可检查发送资格；生产 transport 返回不可用。 |
| 图片 | 传送实际图片数据；接收端复制或显式加入 History。 | 尚未支持。 |
| 文件 | 传送实际文件字节，不传发送方路径；校验后原子保存到用户选择目录。 | 尚未支持。 |
| 超限 / 失效 / 不支持 | 在任何发送前阻止并解释具体原因。 | 未实施实际大小与文件检查；不得声称 100 MB 目标已达到。 |

## 3. 当前架构边界

### 3.1 独立服务与默认拒绝

Local Link 必须保持在单独的 native service 边界。Core 的捕获、SQLite/history/blob、Quick Paste、直接粘贴、删除和回收站不得依赖 transport。WebView 只能调用具名命令获取 UI 安全的 Device/Transfer 摘要并发起用户动作；没有任意 SQL、文件、密钥、socket 或 shell 能力。

生产实现使用不可用 transport 作为默认值：任何主动发送都会给出固定、内容无关的 `transportUnavailable` 失败结果。测试可显式注入 loopback/test transport 以验证状态机；这个 seam 不可在产品或隐私文档中写成网络连接、发现或加密实现。

### 3.2 本地存储与数据最小化

本次迁移新增以下本地数据类型。字段和保留策略必须以最终 migration 为准；当前设计禁止将正文、图片缩略图、发送方路径、来源 App、账号、原始网络地址/端口、会话密钥或私钥暴露给 IPC、日志或传输摘要。

| 对象 | 允许的本地内容 | 重要边界 |
| --- | --- | --- |
| Local Link preferences | `enabled`、`discovery_enabled`、本机显示名称、更新时间。 | 新安装默认均关闭；打开功能不等同于可以发现或连接设备。 |
| Device | 不透明设备 ID、显示名称、对端公开密钥及其 SHA-256 指纹的 schema 槽位、信任状态、配对/信任/撤销/最后活动时间和配对码哈希。 | 当前没有远端握手填充公开密钥/指纹；不是账号或网络目录；不得持久化端点、发现 token、私钥或会话密钥。撤销后不能再用于发送。 |
| Transfer | ID、方向、相关本地 Device/Item 引用、类型、状态、时间、重试次数和有限失败码。 | UI/日志只读元数据，不包含内容。失败、拒绝和撤销不能回显正文或预览。 |
| Pending receive | 测试 seam 的未确认入站正文只能使用进程内存中的短期暂存。 | 确认前不得写入系统剪贴板、Item、Occurrence、Variant、常规 blob、SQLite 或用户目标目录；重启将元数据标为 `payloadUnavailable`。拒绝、取消、撤销、过期、失败和崩溃恢复都必须清理。 |

`Item`、`Occurrence` 和 `Variant` 仍只表示本机历史。未来手动发送只选择一个 Variant 或文件实际内容，绝不传输数据库、标签、回收站状态、删除状态、发送方绝对路径或 Finder 元数据。接收确认后，只有本地完全相同内容才可新增 Occurrence；否则新增 Item。任何接收内容不得自动转发给第三台设备。当前入站 test seam 没有携带发送方 Transfer ID，因此尚不能满足未来协议的重放去重要求；真实 transport 必须增加该 ID 的幂等持久化规则。

### 3.3 本地状态机

| 状态 | 当前含义 | 当前允许操作 | 未来真实 transport 的附加要求 |
| --- | --- | --- | --- |
| pairing | 本地保存的配对意图；六码仅以哈希存储。 | 确认、取消。 | 双端必须确认同一代码；代码不等于身份认证。 |
| trusted | 本地允许选择的设备。 | 创建发送尝试、撤销。 | 必须绑定可验证公开身份，不能由同名/Wi-Fi/Apple ID 自动授信。 |
| revoked | 本地不可发送的设备。 | 重新开始新的配对流程。 | 终止/拒绝新会话并清除未确认预览。 |
| pendingAcceptance | 仅测试 seam 可创建的待确认入站状态。 | 接受、拒绝、撤销。 | 只允许短期内存暂存；不能进入用户剪贴板/History/磁盘。 |
| sent | 仅 test transport 成功时的状态。 | 观察或由未来协议推进。 | 不得等价于“对方已复制”或“内容已使用”。 |
| accepted / rejected / failed | 终态；失败代码为固定枚举。 | 查看无内容元数据；仅失败的出站尝试可重试。 | 未来协议的同一发送方 Transfer ID 最多产生一次接收动作、一次 Item/Occurrence 写入、一次文件写入和一次通知；当前 test seam 尚未实现该协议字段。 |

## 4. 隐私、安全与权限契约

1. 发送前必须再次运行本地捕获隐私策略。暂停、忽略 App 或敏感内容命中时，选中的 Item、Occurrence 或 Variant 在任何 payload 形成/写入/传输前被阻止；菜单、快捷键、重试和 IPC 均不得绕过。
2. Local Link 不请求 Accessibility。Accessibility 仍只在第一次用户直接粘贴时按渐进方式申请；被拒绝、撤销、不可用或目标不可信时仍降级到系统 clipboard 恢复，不发送输入。
3. 真实 transport 若需要任何 macOS entitlement、Local Network 访问、后台服务、登录项、防火墙例外或新增存储目录，必须先说明实际作用范围、更新能力配置和隐私文档，并按双真机验证。
4. 配对码只证明本机用户输入一致，不能替代真实对端认证或加密。选择实际协议前，不能声称“加密”“LAN-only”或“不会对外连接”。
5. 未来文件接收须先进行完整性校验，再以原子方式写入用户明确的目标目录；拒绝、取消、断网、磁盘错误或崩溃都不得留下未声明内容。此机制尚未实现。

## 7. 双真机 macOS Beta 矩阵（真实 transport 后执行）

双真机是两台不同的实际 Mac、独立应用数据目录和真实网络路径。不得用同机双进程、浏览器适配器、test loopback、私人剪贴板、真实凭据或私有文件代替。每条记录构建 SHA、两台设备的 macOS/芯片、网络类型、发现状态、协议版本、日期、操作者及脱敏证据。

| ID | 操作 | 通过条件 | 现在状态 |
| --- | --- | --- | --- |
| LL-M01 | 两台新安装 Mac 在同一网络；一端依次关闭/开启发现 | 关闭时不可见；开启后只暴露已文档化的最小设备信息，无历史或预览泄露。 | 未实现，不可执行 |
| LL-M02 | 正确六码配对；错误码、过期、单端/双端取消 | 正确路径普通用户 60 秒内完成；异常路径无可信关系或可复用会话。 | 未实现，不可执行 |
| LL-M03 | 从 Quick Paste 发合成文本；分别测试无/拒绝/已授予 Accessibility | 发送不依赖 Accessibility；`Enter` 直接粘贴不回归；接收确认前 0 次 clipboard/History 写入。 | 未实现，不可执行 |
| LL-M04 | 接收文本：复制、拒绝、发送方取消、重复投递 | 只处理一次；拒绝/取消无正文残留；发送端状态可解释。 | 未实现，不可执行 |
| LL-M05 | 合成图片、10 MB 合成文件、超限和失效文件 | 接收字节校验正确，超限解释具体，实际文件而非发送方路径；失败无残片。 | 未实现，不可执行 |
| LL-M06 | 离线、Wi-Fi 切换、隔离网络、睡眠唤醒、远端重启 | 无云端排队假象；状态为具体 Offline/Failed；手动重试不重复写入。 | 未实现，不可执行 |
| LL-M07 | 传输/待确认时撤销可信设备并尝试重连 | 新会话立即被拒；未确认预览和临时内容清除；重用需重新配对。 | 未实现，不可执行 |
| LL-M08 | 运行发现/失败传输时覆盖 Quick Paste、History、回收站、全屏、双显示器、Space、中文输入法 | Core 正确性和响应性不退化。 | 当前可做单机失败降级；双机未实现 |
| LL-M09 | 对被忽略 App、暂停捕获、Default/Strict 合成敏感值尝试所有发送入口和 retry | 0 payload 外发、0 正文日志；普通内容仍按策略可用。 | 双机未实现；当前可做 test seam |
| LL-M10 | 通过系统网络观察工具检查配对/传输 | 仅有已文档化的局域网流量，且无外部中继或明文。 | 未实现，不可执行 |
| LL-M11 | VoiceOver、键盘、Reduce Motion、非英语系统语言执行配对、发送、接收、失败、撤销 | 可理解的名称和焦点，状态不依赖颜色。 | 未实现，不可执行 |
| LL-M12 | 空闲 30 分钟、菜单栏后台和睡眠恢复 | 无持续高 CPU/异常网络唤醒；恢复后的可达性与状态正确。 | 未实现，不可执行 |

至少覆盖一对 Apple Silicon 设备和两代受支持 macOS；若发行 Universal 包，再覆盖 Intel。网络环境必须包括普通同网 Wi-Fi 与不可发现/隔离网络。未执行一律保留“未测”，不能借自动化、mock 或单机 loopback 写成“已通过”。

**当前判定：No-Go（真实 Local Link Beta）。** 当前控制面预览可作为隔离、默认关闭的开发工作继续，但不得作为产品方案中的 P0 互传能力验收通过。

只有以下全部满足，才可以改为 Go：

1. 0.5 所有 P0 自动化和真人 macOS 发布门槛通过。
2. 本文所有当前 P0 自动化项通过；任何新增 dependency/lockfile 变化已按 `docs/audit/sbom-license-review.md` 复核。
