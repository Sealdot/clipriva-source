# ClipRiva v1.1 P0 迭代设计与验收用例

- **实施范围：** 文档 `ClipRiva-v1.1-产品优化方案（含配图）.docx` 的 P0 用户故事 US-210—US-250。
- **版本定位：** 日用化改进候选；Local Link 仍为默认关闭的 Preview / Alpha，不能因本文件或自动化测试被称为 Beta。
- **不在本轮扩展：** 账号、云同步、跨公网中继、OCR、标签/知识库、目录传输、协作共享，以及新的图片/自动粘贴能力。

## 目标与设计取舍

本轮把高频路径收敛为“菜单栏或全局快捷键 → 找回 → 复制/显式发送”，将完整管理、设备和设置保留在按需打开的主窗口。所有入口读取同一份本地 History；不引入第二套缓存、同步队列或网络目的地。

| 用户故事 | 落地设计 | 自动化覆盖 |
| --- | --- | --- |
| US-210 主窗口更轻 | 默认 `860×560`、最小 `720×480`，保存窗口大小；默认历史列表，详情抽屉按需显示。 | `App.test.tsx`：详情默认关闭/按需打开；配置与窗口状态手工验收。 |
| US-211 条目统一动作 | 行内 Copy / Send / Pin；Delete 收在 More 菜单；复制显示 1.5 秒完成反馈，删除进入回收站并支持 Undo。 | `ClipboardCard.test.tsx`、`DeleteUndoToast.test.tsx`、`App.test.tsx`。 |
| US-220 Quick Paste 键盘闭环 | 自动聚焦；类型筛选；固定优先、再按最近使用/捕获排序；方向键、Enter 复制并关闭、Space 预览、Esc 立即关闭。 | `QuickPasteOverlay.test.tsx`、`App.test.tsx`。 |
| US-221 Quick Paste 显式发送 | `Command+Enter` 打开现有受信设备选择；发送只创建一次显式 Local Link 请求。 | `QuickPasteOverlay.test.tsx`、Local Link UI/API 测试。 |
| US-230 内容模型 | 文本/链接/代码/颜色的确定性类型归类、规范化、大小边界和连续重复合并；无法归类时按文本安全处理。 | Rust classifier、policy、database 单元测试。 |
| US-240 可信传递 | 6 位配对确认后默认信任 30 天；可选仅本次或始终信任；到期变为“需要重新配对”；传输状态、无正文失败原因和恢复动作通过有穷枚举返回 UI。 | `local_link.rs`、`models.rs` 与 Local Link UI/API 测试。 |
| US-250 隐私与保留 | 新安装默认 30 天；固定条目不受自动清理影响；排除 App 在持久化前即时阻止；原生菜单仅显示本机最近 History。 | Rust policy/database 测试、`privacyBoundary.test.ts`。 |

## 键盘与状态契约

| 场景 | 行为 | 不允许发生 |
| --- | --- | --- |
| Quick Paste Enter | 将选中条目恢复到系统剪贴板并关闭面板。 | 不模拟粘贴键、不改变未选中的条目。 |
| Quick Paste `Command+Enter` | 打开受信设备选择；发送须再次由用户确认。 | 自动同步、离线队列或未配对投递。 |
| Quick Paste Space | 打开/关闭当前项预览。 | 触发复制、发送或持久化新内容。 |
| Quick Paste Esc | 立即关闭，保持系统剪贴板不变。 | 先清空查询、触发删除或自动粘贴。 |
| 删除 | 从索引移至本地回收站，允许短时 Undo。 | 在高频按钮旁静默永久删除。 |
| Local Link 失败 | 返回稳定的失败类别与可恢复动作（新建发送、重新配对、更新应用、检查策略等）。 | 在状态或日志中存储/返回正文、预览、端点或密钥。 |

## 验收用例

| ID | 场景与操作 | 通过条件 |
| --- | --- | --- |
| W-01 | 冷启动主窗口；缩放、关闭再打开。 | 初始大小 `860×560`，最小 `720×480`，上次安全尺寸恢复；未选择时无详情抽屉。 |
| W-02 | 选择条目、打开/关闭详情。 | 历史列表保持可见，抽屉不常驻，焦点和选中态可见。 |
| A-01 | 悬停/键盘聚焦条目，分别 Copy、Send、Pin、More→Delete。 | 四种动作存在 Tooltip/可访问名称；Copy 给完成反馈；Delete 可 Undo。 |
| Q-01 | 打开 Quick Paste、输入关键词、↑/↓、Enter。 | 无鼠标完成搜索、选择、复制、关闭；默认不自动粘贴。 |
| Q-02 | 对有查询的面板按 Esc；对条目按 Space 两次。 | Esc 立即关闭且不写剪贴板；预览可逆且不改变内容。 |
| Q-03 | 固定和非固定记录混合，清空/输入检索。 | 空查询固定优先，之后按最近使用/捕获；有查询时相关性先于最近度。 |
| Q-04 | `Command+Enter` 发送；设备离线、拒绝、超时、版本不兼容。 | 只打开显式设备流程；状态和失败原因可理解，重试不重放旧正文。 |
| C-01 | 依次复制普通文本、URL、代码、颜色、空内容、超限内容、同一内容连续两次。 | 支持类型归类一致；空/超限给无正文原因；连续重复合并为一个条目并增加 occurrence。 |
| P-01 | 将保留期设为 30 天；固定一条已过期内容；清理。 | 非固定过期条目清理，固定条目保留。 |
| P-02 | 添加排除 App 后立即从该 App 复制；检查 SQLite、UI 和诊断。 | 内容不落库、不进入索引/诊断；规则无需重启即可生效。 |
| L-01 | 分别选择仅本次、默认 30 天、始终信任完成配对；重启并让 30 天信任到期后再次发送。 | 仅本次的可用密钥不落盘且重启后失效；30 天到期设备显示需要重新配对且不能发送/接收/接受正文；始终信任仅在显式撤销/重置/重新配对后失效。 |
| L-02 | 传输被拒绝、网络断开、收到不支持项目或身份不可信。 | 返回有穷状态、失败类别和恢复动作；Transfers、日志、IPC、数据库均无正文。 |
| M-01 | 从菜单栏复制最近条目；选择 15 分钟、1 小时、手动暂停；恢复。 | 仅读取/写入本机系统剪贴板；暂停状态清晰，临时暂停到时恢复，手动暂停需显式恢复。 |

## 发布门槛与证据

1. 前端：Biome、TypeScript、Vitest、生产构建通过；关键 P0 测试必须覆盖 Q-01、Q-02、A-01。
2. 原生：`cargo fmt --check`、`cargo clippy -- -D warnings`、`cargo test --locked` 通过；核心策略、留存、Local Link 信任/状态测试必须通过。
3. 隐私：排除规则先于持久化；诊断和 Local Link DTO/Transfers 不包含正文、URL 查询参数、端点、密钥或配对码；不新增云端网络路径、账户、遥测或 OS 权限。
4. Local Link：自动化只构成工程验收；真实双 Mac 的 50 次配对、200 条传输、抓包与磁盘/日志扫描完成前，保持 Preview / Alpha，不能作为 Beta 发布。

## 本轮边界影响

- **隐私：** 菜单栏是同一台 Mac 上的本地 History 可见入口；点击最近条目走既有本地恢复路径。没有账号、云端、远程模型、遥测或新 OS 权限。
- **安全：** 短期暂停只在本机进程内计时；手动暂停保持已有持久化语义。Local Link 仍由 native 层独占网络、密钥、端点和待决正文。
- **许可证：** 未新增直接依赖或第三方资产；无需更新依赖清单或 SBOM/许可证审查。
