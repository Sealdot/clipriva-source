# ClipRiva Core 优化范围与验收指标

本轮以 `ClipRiva-product-brief-and-user-stories.docx` 为产品依据，只优化本地优先的 Core 日用体验；不新增账户、同步、云端 AI、MCP、Agent 或插件 SDK。

## 要做什么

| 用户路径 | 本轮优化 | 方案依据 |
| --- | --- | --- |
| 首次启动 | 隐私说明成为键盘可达的模态流程，聚焦主操作且不会误操作背景。 | US-C01 |
| 历史整理 | 单条删除与清空未置顶均须明确二次确认；置顶状态和操作名称可由辅助技术理解。 | US-C06 |
| 捕获保护 | 暂停状态直接显示暂停原因，并提供一次点击恢复。 | US-C07 |
| 设置 | 设置面板开启、关闭与 Tab 循环遵循键盘焦点；保留现有本地数据、保留规则、应用排除、Quick Paste 和 Labs 开关。 | US-C01、US-C05、US-C07 |
| 视觉与空状态 | 延续现有深色、本地优先的绿色 token；针对空历史、无搜索结果和无置顶内容给出不同的下一步。 | 图 1–5、US-C04、US-C06 |

## 如何衡量

不引入遥测或外部分析。以可复现的本地验证作为发布信号：

| 指标 | 通过标准 | 验证方式 |
| --- | --- | --- |
| Core 测试完整性 | `pnpm check` 完整通过（lint、Vitest、TypeScript、生产构建）。 | 自动化测试 |
| 原生可靠性 | `cargo test --manifest-path src-tauri/Cargo.toml` 完整通过。 | Rust 单元测试 |
| 删除安全 | 未确认单条删除或清空未置顶时，历史不发生变化；确认后才执行。 | 单测与浏览器检查 |
| 键盘可达性 | 首次启动与 Settings 打开后有清晰焦点；Tab 不会进入被遮罩的主界面；Escape 可关闭 Settings。 | 单测与浏览器检查 |
| 状态可理解性 | 暂停提示包含原因与 Resume；空状态说明下一步。 | 单测与浏览器检查 |
| 视觉回归 | 主工作区、首次启动、Settings、Quick Paste 在既定窗口中无裁切、重叠或 token 偏离。 | 本地浏览器截图检查 |

## 不在本轮范围

- 跨设备同步、账户、网络服务、云端模型、遥测。
- 图片 OCR 或完整 DLP 承诺。
- macOS 签名、公证、Universal 包及真实设备兼容性矩阵；这些仍按 `docs/beta-validation-matrix.md` 执行。
