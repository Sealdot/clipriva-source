## Decision and scope

The first pass was M0, followed by review of the [Quick Paste prototype](../design/alpha2-quick-paste-prototype.html). The owner replied “好的” to the prototype handoff, confirming its window density, default Copy action, and degraded wording for implementation. Implement small, reversible CR changes in the existing React/Tauri/Rust code. Preserve Items, Saved (`is_pinned`), manual and Smart Collections, Notes, OCR, settings, and the process-memory Stack. Core remains account-free and offline by default; Labs, automation, and Local Link remain independently gated. This plan does not approve a network/permission expansion, destructive migration, at-rest encryption, signing, notarization, push, tag, publication, or promotion of Local Link.

Design behavior and tokens are in [the UI specification](../design/clipriva-ui-spec.md). Fixtures, commands, evidence definitions, and performance sampling are in [the task protocol](../testing/clipriva-2.0-task-protocol.md). M0 observations and screenshot provenance are in [the evidence record](../release/evidence/m0-91afcd8/README.md). The proposed at-rest decision is in [the ADR](../adr/history-at-rest-protection.md). Existing privacy, module, Local Link, and public-release rules remain binding.

## Sequence and decisions

1. The owner confirmed the light/dark/degraded Quick Paste prototype. This does not grant implementation of any new permission.
2. Implement CR-01 and CR-04 as focused commits, then CR-02/03/07, then CR-05/06. Validate existing-data invariants on synthetic copies. Keep CR-08–10 as separately reviewable protection/release work.
3. Before any new OS permission, network path, destructive migration, at-rest encryption policy, or release decision, present options and impact for explicit owner confirmation. [The ADR](../adr/history-at-rest-protection.md) currently remains proposed.
4. Complete alpha.2 with commit-specific checks, before/after captures, native safety evidence and a remaining-risk list. Only then propose beta work. Local Link stays Preview/No-Go until its independent exact-package gate passes, or a Core stable package is proven to isolate it natively; if isolation fails, Core remains No-Go.

No branch push, tag, signing, notarization or publication is authorized by this plan.
